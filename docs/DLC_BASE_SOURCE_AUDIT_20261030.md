- Stone-Sheathed Sword: wiki infobox/category comparison physical +0 **119**, but same page's published somber +0 row **89**. Withheld base attack, grade, critical instead of guessing. Weight **3.5** source-confirmed.
- Falx: +0 Strength grade **D** in source infobox and class table but **E** in upgrade list; stored `?` for STR, while +0 physical 107 is consistent.
- Messmer Soldier's Spear and Swift Spear: source lists malformed **0** for Faith scaling grade. Stored `?` and no invented grade.
- Madding Hand Faith requirement corrected 20 → **13**; Main-gauche weight corrected 2.5 → **2** from named wiki.gg source.
- Source-reported +0 damage components, including split damage, cannot directly be added together to form a player's accurate AR or predicted damage. Reinforcement/affinity/attribute numeric curves and in-game golden tests are still missing.
