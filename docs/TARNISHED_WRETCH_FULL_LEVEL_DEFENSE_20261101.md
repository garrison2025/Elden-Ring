# Real Tarnished.dev v1.17 Wretch levels 90–713 read-only defensive-stat audit

Seven independent Wretch build sweeps each cover a 90-point interval: previously filled attributes stay 99, current stat increases 10..99, later stats stay 10. This produces 630 actual same-input observations covering all character levels 90..713 with one-row overlaps. Each reads exactly five defense ratings, four resistances and Discovery. Individual full-level snapshots are genuine observations, not formula-derived values.

These full-level outputs, together with the separately observed 8×90 one-axis profiles, permit independent tests of whether level and stat contributions may be separated. Do not assume additivity or general class/build effect parity until the observed mixed profiles agree; hold back an unsafe derived algorithm if they do not.

All test runners use free GitHub Actions Chromium, no game code or paid API.
