About Build Lab

An independent, fan-made collection of Elden Ring calculators focused on careful math, fast tools and visible limitations.

Why we built it

Character planning often combines class selection, allocation and rune budgeting. Build Lab makes those operations interactive without requiring a login, external calculator API or a server-side game database.

Scope and accuracy

Public tools cover attribute allocation, class optimization, rune level costs and equip-load thresholds. Weapons, enemy-damage formulas, item data and spell scaling need additional provenance and game-client checks before publication. Read the accuracy record.

Unofficial fan project

Elden Ring is a game by FromSoftware, published by Bandai Namco Entertainment. This is an independent fan-made tool and is not sponsored by, endorsed by or affiliated with those companies. No official logos, game artwork, sounds or game files are included.
