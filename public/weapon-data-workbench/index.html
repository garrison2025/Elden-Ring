Weapon Data Workbench

Optionally load a pinned public v1.17 community regulation snapshot into your browser, or provide your own compact JSON. Search weapon variants, upgrades, affinities and compare preliminary one-handed and two-handed attack ratings without a server.

RESEARCH — NOT VERIFIED GAME AR. No game-regulation dataset is bundled. Only clicking the external-source button downloads the public, pinned 1.17 community JSON into this browser; no third-party script runs. Extracted game parameters are third-party derived: the upstream project's MIT code license does not independently settle the rights to game-derived data. Structural conversion does not prove current patch parity, spell/status support or precise damage.

1. Load v1.17 public data, or import your own

You control whether to fetch the public data. This optional operation downloads approximately 1.1 MB directly from the pinned Tom Clark GitHub commit; it does not use a paid API, send your build to a server, execute remote JavaScript or cache game data on this site. Its version is 1.17, not a verified 1.17.3 game dataset.

Alternatively choose a compact local .json file containing weapons, calcCorrectGraphs, attackElementCorrects and reinforceTypes. If cross-origin access fails, download the raw upstream JSON and rename its .js extension to .json before importing; the app still parses it as JSON only, never executes it.

What happens to the file?

It is parsed in a local Web Worker. This site does not upload it, persist its contents, or execute code inside it. Clearing memory or closing this page removes the in-memory copy. Network requests for ordinary website files still occur.

Release gate

Exact numerical match in a synthetic test is not game-client verification. For actual AR publication, an authorized versioned dataset, documented formula mapping and independent in-game measurements are still required. Read the evidence comparator and accuracy record.
