    How we stay current

    We watch changes. We do not copy claims.

    We monitor the publicly published Recent Updates section and version label on Tarnished.dev twice a day through a free GitHub Actions workflow. A detected change creates a GitHub review issue. The system may also prepare and safely merge a strictly JSON-only update to the external watch status above after local checks; it never automatically changes our calculator code, game data or first-party release notes.

    01 · Detect

    Identify new, edited, or version-changing update notes.

    02 · Verify

    Check official game patch notes, feature differences and source rights.

    03 · Implement

    Independent code, reproducible test cases and GitHub review.

    04 · Publish

    Only merged, tested Build Lab features appear in this changelog.

    The current official game App 1.17.2 / Regulation 1.17.3 is distinct from the pinned public v1.17 reference source used by the optional weapon AR calculator. A competitor's update notice is a research signal, not authoritative proof of numerical correctness.
