  1. Oct 31, 2026

    Weapon AR: whole v1.17 source ranking with paginated results

    After explicitly loading the pinned community v1.17 source, you can now rank all available source variants, not just 240 matching entries. The Worker computes nominal AR for every eligible source entry, while the browser displays 100 sorted results per page; CSV exports the entire computed result. Filter Regular/Somber upgrade paths and minimum attributes separately. Existing source gaps and unsupported combinations are reported rather than guessed. This is not complete Tarnished.dev feature/data parity, current Regulation 1.17.3 certification, or enemy damage simulation.

  2. Oct 31, 2026

    Weapon database: source-quality filters and instant requirement reranking

    Filter the bundled source weapon records by complete published +0/requirements/weight fields, incomplete or disputed fields, source conflicts and the 72 recovered research-only reference previews. Counts are generated from the exact bundled JSON, not hand-maintained. When sorting by missing one-hand attribute points, changing a character stat now refreshes the ranked list immediately. Unknown and source-disputed fields remain unavailable for numerical calculations. Field coverage does not establish accuracy for the current game patch; weapon data pages remain noindex.

All weapon AR, database and experimental pages remain noindex until separately approved.

    How we stay current

    We watch changes. We do not copy claims.

    We monitor the publicly published Recent Updates section and version label on Tarnished.dev twice a day through a free GitHub Actions workflow. A detected change creates a GitHub review issue. The system may also prepare and safely merge a strictly JSON-only update to the external watch status above after local checks; it never automatically changes our calculator code, game data or first-party release notes.

    01 · Detect

    Identify new, edited, or version-changing update notes.

    02 · Verify

    Check official game patch notes, feature differences and source rights.

    03 · Implement

    Independent code, reproducible test cases and GitHub review.

    04 · Publish

    Only merged, tested Build Lab features appear in this changelog.

    The current official game App 1.17.2 / Regulation 1.17.3 is distinct from the pinned public v1.17 reference source used by the optional weapon AR calculator. A competitor's update notice is a research signal, not authoritative proof of numerical correctness.
