Record real game-menu evidence for the seven disputed weapons

Use this form only while viewing the actual game. It records all five +0 weapon-detail attack components or the five requirement values, not your character's total Attack Rating. Select two local screenshots: the version/title screen and the weapon details. The browser computes SHA-256 file fingerprints; screenshot pixels are not uploaded, inspected or included in JSON.

All exports are UNREVIEWED evidence drafts. Matching one published source, matching a screenshot's hash, or manually typing version numbers never means independent gameplay verification.

Source readings load locally. No game observation is prefilled.

Each picture must be a real PNG/JPEG/WebP file of at most 12 MB. This form only verifies file signatures and SHA-256 bytes, not that the image actually depicts the stated game, patch or weapon.

Source & licence policy

Data in this preview is limited to small published numerical facts and independently implemented rules. The ERDB data parser is MIT-licensed code, but that license does not automatically authorize redistribution of all data/assets extracted from the game. A different comprehensive public calculator repository offers no license declaration; no code, images, or tables have been copied from it.

Before publishing AR/damage, require a traceable source licence, a versioned data snapshot and in-game comparison samples (base/DLC weapons, upgrades, affinities, 1H/2H, PvE/PvP).
