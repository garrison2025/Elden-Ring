Bring your own parameters (research only)

Load a local JSON file or edit the profile. Required fields: per-affinity base damage; five attribute coefficients; exact 151-point correction curves; attribute/element impact and override rules; reinforcement damage and scaling multipliers. Missing levels are rejected rather than guessed.

The full JSON is read locally in your browser. This preview rejects profiles claiming verified status; real data publication requires independent licence review, actual game-version check and golden tests.

What's implemented — and what's not

  • Implemented: 5 separate damage types, stat scaling, two-hand strength adjustment, minimum-attribute penalties, scaling overrides, affinity and upgrade selection, JSON validation, final rounding, and missing-parameter refusal.
  • Not implemented: actual game weapon profiles, ashes of war, status effects, enemy defenses, motion values, buffs or end-to-end in-game AR accuracy.
  • Current regulation reference: App 1.17.2 / Regulation 1.17.3; this demo does not reflect any regulation's real numbers.

Algorithm reference: ERDB AR calculation documentation. Full validation gate is in verification status.
